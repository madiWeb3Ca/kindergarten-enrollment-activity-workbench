# 外联资源库表 · 字段骨架 v1

> 粒度：一场所一行。表用豆包内置打通的多维表格，落品宣项目空间；本表只记合作方信息，不记家长线索。
> 建表形态三级降级：在线多维表格 → 本地 Excel（`init_tables.py --format xlsx`）→ MD 文本（`--format md`）；字段以本骨架为准。

## 方案卡场地卡 → 资源库字段映射

方案卡里的场地卡信息，本场结束后按下表回填本资源库；一场所一行，不靠复制粘贴保持一致。

| 方案卡场地卡项 | 资源库分区·字段 |
|---|---|
| 场所名称、地址 | 基础·名称、地址 |
| 所属社区/对接主体、对接人、职务、联系方式 | 接洽·对接人、职务、联系方式、合作方式 |
| 距离车程 | 基础·距离车程 |
| 容量、可办时段、室内外、雨天备选、费用 | 条件·容量、可办时段、室内外、雨天备选、费用 |
| 本场到场组数、留资数、转预约数、合作顺畅度与下次注意点 | 效果·到场组数、留资数、转预约数、复盘备注、更新日期 |

## 分级规则

| 级别 | 判断标准 | 动作 |
|---|---|---|
| P0 | 已合作或关系熟；在读家庭集中 | 优先排期，深化合作 |
| P1 | 距离近/家庭密度高；待接洽 | 列入近期接洽清单 |
| P2 | 条件一般或竞对密集；暂缓 | 暂不投入，定期回看 |

## 填写规则

1. 一场所一行；同一社区居委会与物业若分属不同对接主体，分两条记录。
2. 接洽状态随进展更新；已合作场所回填历史效果。
3. 联系人/费用/容量未确认时留占位，不编造。
4. 通知渠道（物业群/公告栏/居委会通知）记入复盘备注，作为下次接洽依据。
5. 资源库条目与活动档案通过场所编码/场次编码关联，不靠复制粘贴保持一致。
