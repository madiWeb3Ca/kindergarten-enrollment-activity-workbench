# 活动档案表 · 字段骨架 v1

> 粒度：一场活动一行。表用豆包内置打通的多维表格，落品宣项目空间；谁用 skill 跑这场活动谁就地回填，成品回交母版。家长联系方式不进本表（留招生岗受控库）。
> 建表形态三级降级：在线多维表格 → 本地 Excel（`init_tables.py --format xlsx`）→ MD 文本（`--format md`）；字段以本骨架为准。

## 填写规则

1. 一场一行；两场链路（走出去＋请进来）分别建档，场次编码互相关联。
2. 漏斗数字只记事实；缺数据留空，不估算。
3. 敏感口径（班额、师生比、费用、名额、荣誉、直升）不进活动档案正文。
4. 复盘结论同步回流到资源库条目与原型配方；回流动作在改进项里标注。
5. 历史档案复用时，当时数字须重新核实后再引用。
