# 第⑦⑧步 · 回头看效果与存下下次再用

> 第⑦步复盘验证：有没有用、断在哪一环、反馈什么、哪里改。第⑧步迭代回流：结论回灌成下一轮资产，形成自循环。

## 一、复盘时机

- **正式复盘攒到链路第二场**（园内探园/体验课）之后，两场数据合并看；单场不急于下结论。
- **当天先记原始记录**：到场、留资/加微/预约数、家长原话反馈、现场异常卡点，防记忆衰减；正式复盘在第二场后汇总。

## 再次进入时的回填触发（挤牙膏式补齐）

> 老师通常没有"活动结束专门回来复盘"的习惯，不等他主动汇报。把回填挂进他下次必然会走的入口：再次使用工作台时，AI 主动把没闭环的上一场翻出来，要一点补一点。

**触发与不触发的入口（选 A）**

| 入口类型 | 例子 | 是否触发回填询问 |
|---|---|---|
| 产出型入口 | 办新一场活动（模式 A）、排系列期（模式 B）、记/更新资源建档（模式 C） | 触发：先查上一场闭环没有，缺了轻量问一句 |
| 纯回看入口 | 翻旧报告、查历史档案、查场地资源、只聊思路 | 不触发：不主动催回填，不打扰 |

**未闭环判定**：活动档案存在，且满足任一即算待闭环——
- 复盘段（断环环节／家长反馈主题标签／改进项）为空；
- 后段漏斗（到园试听/探园、后续报名）未回填；
- 创新动作反馈标签（跑成／一般／未跑成）为空。

**触发动作顺序**

1. 进入产出型入口前，先查活动档案表有无未闭环的上一场；没有就正常进本场流程。
2. 有则先报一行摘要：场次、场地、已有的漏斗数、上次断在哪环。
3. 只问最小集，一次一小卡，不连问一串：
   - 哪些环节跑成／没跑成（含本场新动作反馈）；
   - 后段到园／报名结果；
   - 家长反复提的顾虑或原话主题。
4. 答多少回填多少；本次答不上的留【待核实】占位，下次进来接着要；不编造、不追第二次、不卡住本场方案。
5. 回填后再进本场：跑成的动作进本场配方，踩过的坑进兜底分支。

**时间口径**：不卡活动当天或近期，隔段时间回来也可触发；隔得久（跨招生窗口）只挑关键一两项，不翻旧账全问。

**与正式复盘的关系**：本节是"再次进入时的轻量召回回填"，补活动结束到下次复用之间的数据空档；正式复盘仍攒到链路第二场后合并看，两者不冲突。

## 二、复盘三问

| 问题 | 看什么 |
|---|---|
| 断在哪一环 | 对照漏斗：到场→留资→加微→预约→到园，哪一环流失最多 |
| 家长反馈什么 | 关注点、顾虑、意见；按主题标签归类，不记流水账 |
| 哪里要改 | 环节/时段/物料/伴手礼/话术，哪些保留、哪些调整 |

复盘结论要落到"下次改哪一句、换哪个材料/环节"，不写"本次活动效果良好"这类总结话。

**主动洞察（不等老师自己看数据）**：攒到两场数据后，AI 主动对照漏斗指出流失最异常的一环，结合家长反馈给出"下次优先改哪一环"的建议；建议只基于过程事实，不预设达标线、不推断未成交原因。

## 三、回流去向

| 回流去向 | AI 加持版（本 skill 定位） | 人工常规版对照 |
|---|---|---|
| 社区资源库 | 存居委会/物业联系人、场地条件、通知渠道、合作方式、本场效果 | 同左（人工常规场景主要记这一项） |
| 活动原型字典 | 本场验证有效的变形组合沉淀为可复用配方，下场调用时再按新场地变形 | 不单独沉淀，只写本场简单总结 |
| 线索分层规则 | 沿用现有状态机归置活动线索；复盘发现缺场次/片区字段时，只在新表模板提建议，不动旧表 | 沿用现有状态机，不单独立回流动作 |
| 创新动作验证 | 本场采纳的外来借鉴打法/自创亮点，按过程事实标注跑成/一般/未跑成，跑成的沉淀为可复用配方；未跑成记原因避免重复试错 | 不单独记录创意来源 |
| 下一轮输入 | 复盘结论反哺下一场第①步定入口、第②步盘家底，形成自循环 | — |

## 四、两张新增表的归属

| 表 | 粒度 | 装什么 |
|---|---|---|
| 活动档案表 | 一场一行 | 本场方案要点、漏斗指标、复盘结论、回流条目、关联资源场所；HTML 方案卡作为美观视图挂该行或单独导出 |
| 外联资源库表 | 一场所一行 | 合作方基础信息、接洽状态、场地条件、合作方式、历史效果、关联场次编码 |

字段骨架见 `tables/activity-archive.md`、`tables/outreach-resource.md`。

### 录入与回流规则

1. **自动建表、人工确认**：两张底座表由工具按三级路径初始化（在线多维表格 → 本地 Excel → MD 文本，见下）；建表、配字段、调关联不派给使用者手工完成。每场活动/每个场所的回填条目由 AI 出初稿，人核对时间、地点、联系人、费用、师资、名额后落库。
2. **母版回流**：成品方案、有效打法、复盘结论回交母版；个人库是工作区，母版是汇总正本；第一阶段先各自就地录，跑一段时间后人工汇总去重分级。
3. **读取跟随**：参考历史活动或合作资源，去对方库或母版读；既有招生工作台与意向台账原样不动，需要时只读这两张新表。
4. **编码关联**：档案、资源条目、线索段挂场次编码/场所编码；不靠复制粘贴保持一致。
5. **隐私边界**：家长线索与联系方式留招生岗受控库，不进品宣共享表；资源库只记合作方信息。

### 录入时点分段（两张表各分两段录，不要求一次填全）

| 表 | 第一段（先录） | 第二段（跑完回填） |
|---|---|---|
| 活动档案表 | 活动当天：原始记录——到场/留资/加微/预约数、家长原话、现场卡点；数字只记事实，不补估 | 链路第二场后：到园/试听、后续报名结果、断环环节、反馈标签、改进项；单场不下转化结论 |
| 外联资源库表 | 接洽阶段：名称/类型/地址/距离/来源/对接人/状态/合作方式/场地条件；未知留空不编 | 合作跑完：最近到场/留资/转预约、复盘备注、更新日期；未合作只留接洽记录，不填效果 |

### 四类开口句式（照着说，一次一小卡，不连问一串）

1. **活动当天记原始记录**："今天这场到场几组、留资几个、加微几个？家长反复提了什么、现场卡在哪一步？数字记事实，没记清的先留空。"
2. **第二场后补复盘**："上次那场后来到园/试听了几组、报名几组？哪个环节跑成、哪个一般、哪个没跑成？家长最常提的顾虑是什么？"
3. **新场所进库**："这个社区/商场/机构叫什么、在哪、离咱们多远？怎么找到的、对接人是谁、现在谈到哪一步？条件和费用不确定的先留待核实。"
4. **更新老场所效果**："上次在这个场地办的那场，到场/留资/转预约各多少？合作顺不顺、通知渠道效果怎么样、下次要注意什么？"

> 以上是教练/招生老师对园方或合作方的开口参考；现场不追问家长隐私字段（出生日期、性别、参与人姓名等留回访或 H5 阶段补）。

### 工具口径

- **三级建表降级**：① 首选豆包内置打通的在线多维表格，由 AI 按 `tables/` 骨架直接新建；② 环境不支持在线表时，用 `scripts/init_tables.py --format xlsx` 生成本地 Excel 工作簿；③ Excel 也生成不了时，`--format md` 出 Markdown 表结构文本。不要求园方单独安装飞书；在线表归品宣项目空间，招生岗经链接只读；不单独做组织权限开通核验。
- 历史档案复用时，打法结构可参考；当时事实数字须重新核实，不直接沿用旧数据。

## 五、资源分级规则

| 级别 | 判断标准 | 动作 |
|---|---|---|
| P0 | 已合作或关系熟；在读家庭集中 | 优先排期，深化合作 |
| P1 | 距离近/家庭密度高；待接洽 | 列入近期接洽清单 |
| P2 | 条件一般或竞对密集；暂缓 | 暂不投入，定期回看 |

> 注意：这里的 P0–P2 是场地接洽优先级，与 `entry-layers.md` 的年龄层 P0–P4 是两套编号，不要互套。

## 六、自循环闭环

```
第①步定入口 → 第②步盘家底 → 第③步选原型 → 第④步搭方案
→ 第⑤步校验 → 第⑥步留痕 → 第⑦步复盘 → 第⑧步回流
        ↑______________________________________________|
```

复盘结论回流后，下一场从第①②步重新校准：入口有没有变、家底有没有新增、原型配方要不要调整。
