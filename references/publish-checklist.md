## 二、打包前必做顺序

1. **流程试跑微调**：用真实案例把八步走一遍，记录提示词与流程卡点，先改口径。
2. **一致性校对**：全目录核对步骤名、漏斗字段、表字段、分层与分级规则，消除前后不一。
3. **补 R 异常分支**：脚本空文件/损坏/编码/越界给中文提示。
4. **补 C 集中 FAQ**：`references/faq.md`，并在 SKILL.md 索引登记。
5. **补 A 适用性声明**：不代运营、不承诺结果。
6. **双版剥离**：内部版可留项目专有口径；公共版把校名、社区、企业、坐标、具体户数/距离替换为通用示例。
7. **见证留痕**：跑 `selftest.py` 存档输出；示例档案过 `check_plan.py` 0 告警；写安装说明与 CHANGELOG。

## 五、双版口径边界

| | 项目内版 | 公共发布版 |
|---|---|---|
| 用途 | 挂本项目品宣库对话调用 | 上 SkillHub/GitHub 公共空间 |
| 专有事实 | 保留项目背景与案例占位；已确认事实与待核实项分开标注，待核数字不写成事实 | 全部替换为通用幼儿园示例 |

| 数据 | 真实台账只读参照，不入包 | 只留模拟演示数据并标注 |

### 5.1 公共版剥离核对表（发布前逐项核对）

> 下表为公共版必须通用化的类别；具体名称与数值不得固化进包。替换后全目录再 grep 一遍，确认无残留。

| 类别 | 公共版口径 | 出现位置 | 替换要求 |
|---|---|---|---|
| 园所校名 | 包内正文不写死校名，运行时检索母版；示例以"本园/某幼儿园"指代 | 全 references/SKILL | 不出现具体校名 |
| 社区/楼盘/街道 | 某社区/某小区/某街道 | 示例场地卡、编码示例、自测夹具、脚本说明 | 地名一律占位 |
| 道路/坐标 | 某路附近；坐标不入包 | 示例场地卡 | 不写具体道路与经纬度 |
| 合作方 | 某物业/某居委会/某商场 | 示例场地卡 | 不写企业全称 |
| 规模/距离 | 户数、交房年限、距离车程全部留占位 | 示例场地卡 | 不保留具体数值与估算距离 |
| 场次编码示例 | `2027Q1-某社区-01` 通用格式 | 表模板、留资篇、自测夹具 | 编码不含真实地名 |
| 演示台账数字 | 各层条数以初始化后台账为准 | 入口分层篇 | 不预置具体条数 |
| 竞对名称 | 只记"竞对待核" | 示例场地卡/待核实清单 | 不引入具体竞对园名 |
| 待核联系人/费用/名额 | 全部【待核实】占位，不编 | 全示例 | 同占位口径 |

### 5.2 事实分级与复检规则

1. **事实分级标注**：公开可查的写"公开可查"；计算值标"计算值，非实测"；联系人/费用/名额/户数/竞对未确认的，一律【待核实】，不写成既定事实。
2. **示例头部声明**：`examples/` 档案标注"通用演示示例，地名/机构均为占位，实际使用时替换为本园周边真实场所"。
3. **包内不固化园所事实**：班型、师资、名额、收费、在园人数不写进 references 与脚本；运行时从项目空间母版检索，找不到留占位。
4. **公共版复检**：替换完成后 grep 校名、社区名、企业名、坐标、具体户数/距离，确认 0 残留再打包。
