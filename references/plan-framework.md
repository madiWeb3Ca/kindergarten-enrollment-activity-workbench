# 第④⑤步 · 搭出本场方案：九要素骨架与量力校验

> 第④步把原型落成本场可执行方案；第⑤步掂量人/时/钱/物/渠道撑不撑得住，撑不住就按降级预案砍。方案另一位老师拿到就能办，不依赖“现场自己把握”。

## 〇、方案卡标准章节骨架（固定顺序，写作与校验唯一口径）

> 所有方案卡——无论 AI 写还是老师写——一律按下表顺序组织；`check_plan.py` 按此顺序校验，章节乱序即报错。章节可写短，但不得调换顺序、不得跳号后插。

**头部信息块（不占编号，置顶）**：场次编码、日期/时段、场地、主干模式、场所类型、主攻年龄层、决策窗口、主目标。

| # | 章节（常见别名） | 回答的问题 | 对应八步 |
|---|---|---|---|
| 1 | 先定招谁（入口与目标） | 招谁、什么窗口、主目标、两场链路 | ①定入口 |
| 2 | 手里有什么·自家家底 | 我有什么资源、缺口在哪 | ②盘家底 |
| 3 | 手里有什么·周边场地 | 合作方/场地条件、费用 | ②盘家底 |
| 4 | 供需交换象限 | 双方交换什么、成不成立、投入档位 | 前置闸门 |
| 5 | 找个现成样子（原型选择） | 借鉴什么原型、核心规则 | ③选原型 |
| 6 | 搭出本场方案（动线/流程） | 环节结构、流程时长 | ④搭方案 |
| 7 | 物料与分工（含筹备倒排） | 谁出什么、岗位、倒排 | ④搭方案 |
| 8 | 掂量够不够做（八维校验） | 能不能做、缺口处置 | ⑤量力校验 |
| 9 | 预算（占位待核） | 花多少钱 | ④搭方案 |
| 10 | 风险预案（含降级） | 出问题怎么办 | ④⑤ |
| 11 | 推荐动作与本场亮点 | 首选/备选/亮点 | ④搭方案 |
| 12 | 当天怎么留线索 | 两码、三分支、漏斗归因 | ⑥留线索 |
| 13 | 回头看与存下下次用 | 复盘、回流 | ⑦⑧ |
| 14 | 待核实清单 | 哪些待确认 | 全程 |

弹性规则：
- 非异业/纯园内场：第 4 供需象限可简化为一句“无外部合作方”，但位置不变。
- 线上蓄水/纯物料植入：执行手册可豁免，方案卡章节顺序不变。
- 某章节无内容时写“无/待填”占位，不删除、不挪位。

## 〇·五、写作防补丁规则（唯一主位与顺序纪律）

> 边聊边改最容易出现“顾后不顾前”：同一件事在好几章重复、前一章引用后一章才定义的概念、结论先于论据出现、参考类型混用。以下规则用于压住补丁堆积；`check_plan.py` 对可机检的三条（前置引用、结论前置、内容传播词混入同业依据）给出软警告，其余为人工写作纪律。

### 信息唯一主位（一条信息只在主位讲透，他处只写指针）

| 信息项 | 唯一主位章节 | 其他章节写法 |
|---|---|---|
| 岗位×人数×职责分工 | 七、物料与分工 | 第六章动线只挂岗位名，不重复职责描述 |
| 合作双方/三方交换条件与匹配判断 | 四、供需交换象限 | 第七章只列物料与职责归属，不重谈供需判断 |
| 降级档位与砍法 | 十、风险预案 | 第八章缺口、第十一章备选只指针指向第十章，不重复具体档位 |
| 预算品项与占位 | 九、预算 | 第八/十章只引用，不重列品项金额 |
| 缺口清单（缺什么、待核实什么） | 八、掂量够不够做 | 只列缺口，不下最终结论；处置动作指向第十章 |
| 留资字段、三分支、跟进节奏 | 十二、当天怎么留线索 | 他处只提“见第十二章” |
| 复盘结论与打法回流 | 十三、回头看 | 不在方案前段下效果/转化结论 |

### 四条顺序纪律

1. **不前置引用**：前一章不得引用后一章才定义的站点编号或环节名。原型章（5）的经验依据按通用“接触环节”组织，五站定义归第六章；不得在第五章出现“第 N 站”这类第六章站点编号。
2. **结论后置**：可行性结论只能出现在预算（九）、风险与降级（十）之后。第八章只盘点缺口，不在风险预案之前下“能不能做/可执行”结论；结论统一落在第十章末。
3. **一章一职责、不堆补丁**：新增内容先归位到对应章节，不往已有章里塞；一章要么有独立信息，要么是指针，不做无信息增量的复述。
4. **参与方口径一致**：园所／合作方／摊主家庭等参与方，在供需象限、分工、留资各章的名称与身份一致；新增参与方先在供需象限登记，不在分工章临时冒出新角色。

### 同业依据边界（参考类型不能混用）

| 调研类型 | 研究对象 | 可用于 | 不可用于 |
|---|---|---|---|
| 活动案例（《异业合作成功案例参考》等） | 园所×机构真实跑通的活动 | 第五章同业依据、活动做法借鉴 | — |
| 内容传播调研（三平台官方号爆款调研等） | 幼儿园官方号自己拍的视频怎么传播（小红书/抖音/视频号） | 视频/内容那条线：视频教练、官方号运营 | 活动方案的同业依据、活动设计 |

1. 第五章“同业成功经验／同业做法”只能引用**真实活动案例**，写清案例全称（园所×机构）、来源与可信度；查不到可验证活动案例就标“待核实”，不许用内容传播结论顶替。
2. 内容传播类指标（三平台、官方号、点赞、收藏、播放、涨粉等）**不得作为活动设计依据**出现在同业依据列；活动当天若要安排拍摄，归视频/内容那条线，不在活动方案卡内展开。

## 一、方案九要素（第④步）

| 要素 | 要落定什么 | 不合格信号 |
|---|---|---|
| 场地 | 具体场所、室内外、容量、可用时段、雨天备选 | 只写"社区里"，没定具体场地 |
| 环节结构 | 亲子体验／家长答疑／留资邀约怎么分段；答疑不开成讲座 | 只有环节名，没有分段逻辑 |
| 流程时长 | 各环节分钟数，合计对得上总时长；钟点待排期处占位 | 环节时长加起来对不上总时长 |
| 物料 | 绘本/教具/手工包/伴手礼/展示物料/登记物料，可复用先标复用 | 写"若干""适量"，明天备不齐 |
| 分工 | 园所出什么（老师/内容/方案/物料/活码/登记），合作方出什么（场地/通知/协助）；各角色到人 | 分工只写"大家配合" |
| 预算 | 人手、常规物料、伴手礼；场地费待确认；品项单价总额占位，不编数字 | 直接写金额、报价 |
| 时段 | 周末/工作日、上午/下午；具体钟点待排期占位 | 没有时段，通知没法发 |
| 风险预案 | 儿童安全/情绪、超员、留资自愿、口径合规、突发处置与应急联系人 | 只写"注意安全" |
| 两场链路 | 第一场走出去留资 → 第二场请进来体验/探园；线索编号互相关联 | 单场孤立，没有承接下一环 |

## 二、流程草稿示例（社区亲子坊，约 65 分钟，仅示范结构）

| 时段 | 环节 | 要点 |
|---|---|---|
| 0–10' | 签到登记 | 现场表单/纸质兜底；发场次编号 |
| 10–25' | 绘本阅读打底 | 中教带读，低龄安静活动 |
| 25–35' | 外教穿插 | 英文儿歌/手指谣/打招呼，控时长 |
| 35–50' | 分段答疑 | 孩子由中教带安静活动；家长答疑 10–15 分钟 |
| 50–65' | 互动留资＋邀约探园 | 领礼、留资码/邀约码；不催当场报名 |

> 分钟数与钟点是草稿，正式方案以排期和场地条件为准。

## 三、筹备倒排 SOP（D 日＝活动当天）

提前量是参照区间，按本场筹备周期和场地接洽难度调整；节点可并行，但场地档期与师资档期未确认前，不对外发报名通知。

| 节点 | 相对 D 日（参照） | 责任人角色 | 产出物 | 卡点 / 待核 |
|---|---|---|---|---|
| 接洽定场 | D-14～D-10（商场/社区档期慢，宜更早） | 招生负责人/答疑 | 场地意向、合作条件、通知渠道、合作方式 | 场地规则、费用、容量、可用时段待对方确认 |
| 定方案与分工 | D-10～D-7 | 中教/答疑/协助 | 方案卡九要素、岗位分工表（岗位×人数×职责） | 可出场师资与档期；凑不齐先按降级减环节 |
| 通知报名 | D-7～D-3 | 招生/渠道 | 预告内容、报名/留资入口（带场次参数） | 物业群/公告栏/会员群能否覆盖目标家庭 |
| 备课彩排 | D-3～D-1 | 中教/外教 | 体验片段定稿、答疑口径稿、常见问题清单 | 答疑口径 AI 初稿人工复核；敏感口径留面谈 |
| 物料到位 | D-2～D-1 | 协助/后勤 | 物料分级清点：复用库存／采购／制作三类齐套 | 伴手礼、邀约码卡片、登记物料、两码测试 |
| 当天执行 | D 日 | 全员 | 按当天执行 checklist 推进 | 天气/场地/工具兜底；纸质登记兜底备好 |
| 当天记录 | D 日当晚 | 登记协助/答疑 | 原始记录：到场、留资、加微、意向数；家长原话；现场异常卡点 | 数字只记事实，不补估 |
| 复盘回流 | 链路第二场后 | 全员 | 复盘三问、活动档案归档、资源库回流 | 单场不下转化结论；结论反哺下一场 |

## 四、当天执行 checklist（五段时点）

### 开场前 30 分钟

- [ ] 场地布置到位；安全排查：尖角软包、视线覆盖、安静角落、无尖锐小件
- [ ] 物料就位：绘本教具、手工材料、登记物料、两码（留资码/邀约码）、伴手礼
- [ ] 表单/活码测试可用；纸质兜底表与笔备好
- [ ] 岗位碰头：分工、流程节奏、应急联系人、雨天/场地变更备选确认
- [ ] 对照 `contingency-playbook.md` 高频条目（★）预读本场最可能遇到的分支

### 签到段

- [ ] 引导入座、安抚孩子情绪；哭闹孩子专人带安静角落
- [ ] 登记留场次编号；核对月龄段（岁口径）
- [ ] 纸质兜底只记称呼＋电话，回去由招生老师补录

### 环节中

- [ ] 按流程样板推进，控制各环节时长
- [ ] 视线覆盖孩子；低龄不做剧烈跑跳
- [ ] 答疑分段进行，不开成讲座；敏感口径留面谈
- [ ] 记录现场卡点、家长高频问题、孩子状态

### 收尾段

- [ ] 领礼环节引导扫留资码；有意向的递邀约码（回家扫）
- [ ] 不催当场报名；提醒邀约码回家扫选时段
- [ ] 物料回收、场地复原

### 离场后

- [ ] 清点物料与剩余伴手礼
- [ ] 当晚把原始记录落表：到场/留资/加微/意向、家长原话、异常
- [ ] 线索按三分支归置（当场敲定／待跟进／长期维护）
- [ ] 异常与反馈记入复盘待办

## 五、风险预案清单

| 风险类型 | 预案要点 |
|---|---|
| 儿童安全/情绪 | 场地排查尖角软包、视线覆盖、留安静角落；低龄活动不做剧烈跑跳 |
| 陪同模式 | 两模式并列：设活动角由我方老师陪同；不设活动角则家长全程陪同、园所不托管，不安排脱离视线环节，动线防攀爬 |
| 超员 | 报名设上限；分组分批 |
| 留资自愿 | 不强迫填写；信息按岗位受控 |
| 口径合规 | 不贬同行、不编事实、不承诺名额费用；敏感口径留面谈 |
| 突发处置 | 应急联系人、物料备份、天气/场地变更备选 |
| 物料复核 | 海报/通知/流程表 AI 初稿人工复核后对外 |

> 上表是静态风险档位；当天各类突发状况（孩子/家长/师资/物料场地/人流线索）的即时应对、转圜兜底与顺势加分动作，见 `contingency-playbook.md`。

## 六、量力校验表（第⑤步）

逐维度标状态（现成／待补／待核），写清缺口与处置：

| 维度 | 校验问题 | 缺口处置 |
|---|---|---|
| 人手 | 出场人数、角色（中教/外教/答疑/登记协助）、档期 | 排出场名单；凑不齐按降级预案减环节 |
| 时间 | 筹备周期：接洽→通知报名→备课彩排→物料；活动日期 | 日期待排期；倒排筹备节点 |
| 预算 | 伴手礼/物料单价总额；场地费 | 占位待核；先按轻预算估结构，不编金额 |
| 物料教具 | 现有绘本/教具可复用；伴手礼采购清单 | 先盘点复用，缺项列采购 |
| 场地 | 容量、桌椅、音响、可用时段、场地规则 | 待合作方确认；不满足换场地或缩规模 |
| 通知渠道 | 物业群/公告栏能否覆盖目标家庭；自有渠道预告素材 | 接洽时确认；预告素材先备 |
| 答疑口径 | 家长常见问题清单；敏感口径留面谈 | AI 出初稿、人工复核 |
| 留资工具 | 活码/表单/H5 环境；预约结果如何回写 | 待确认工具环境；纸质兜底先行 |

### 校验结论分三种

- **可执行**：八维度无硬缺口，进第⑥步。
- **补缺口后可执行**：列出待补项与负责人，占位不阻塞流程。
- **撑不住**：启动降级预案，或换更小原型/推迟到下一窗口。

## 七、降级预案（撑不住时按顺序砍）

1. **一档**：伴手礼实物改电子探园邀约券。
2. **二档**：外教穿插改中教带安静律动/游戏。
3. **三档**：缩小规模、限报名组数、答疑缩到 10 分钟。

降级只砍环节与规模，不砍安全预案与留资自愿原则。

## 八、本场产物清单（方案卡 vs 执行手册）

模式 A 单场活动按下表出产物；缺件先补再交付，目录齐套由 `scripts/check_deliverables.py` 检查，不靠临场想起来。

| 产物 | 回答的问题 | 内容骨架 | 必出条件 |
|---|---|---|---|
| 方案卡 HTML＋`.md` 底稿 | 办什么、双方给什么、边界在哪 | 入口、家底、原型、九要素、供需象限、量力校验、风险预案、留资归因、复盘口径 | 必出 |
| 执行手册 HTML | 谁在几点做什么、判断点没过怎么降级、现场出状况怎么接 | 六阶段 SOP＋当天分段 checklist＋现场分支速查表 | **有线下现场环节的单场活动必出**；线上蓄水/纯物料植入可豁免 |
| 复盘记录 | 这场哪里跑成、哪里没跑成 | 当天原始记录＋第二场后三段式复盘；并入活动档案表 | 赛后出 |

**同源纪律（MD↔HTML 不漂移）**：方案卡 HTML 只能由 `render_html.py` 从 `.md` 底稿生成，禁止手改网页版；改动只落 MD，再重渲染 HTML，两版成对交付。齐套检查按同名配对比对修改时间，MD 晚于 HTML 会软告警"底稿晚于网页版"，提醒重渲染；不允许 MD 与 HTML 各改各的。

**手册豁免**：纯线上蓄水场、纯轻型物料植入/礼品赞助（不派人、不办现场活动）可不出手册，但必须在方案卡显式标注"手册豁免＋原因"，齐套检查据此跳过。其余单场活动（走出去驻点/快闪、请进来探园日/体验课/联办、社区室内场）一律出手册；方案卡里已有流程倒排不等于手册，不能以此省略。

**执行手册六阶段骨架**：
1. 对接定场与资质/条件核实（D-14～D-10）：对接状态、资质审核、合作条款、判断点与不满足分支；
2. 定方案与双方分工（D-10～D-7）：流程时长、岗位×人数×职责泳道、两场链路；
3. 通知与工具筹备（D-7～D-3）：预告素材与邀约口径、两码测试、纸质兜底；
4. 备课物料与彩排（D-3～D-1）：口径把关、讲解稿/脚本、物料三类清点、场地动线复核；
5. 当天执行（D 日）：开场前 30' 布置碰头 → 签到 → 环节控场 → 参观/体验 → 收尾留资 → 离场清点与当晚记录；
6. 离场后跟进与复盘（24h／3 日／第二场后）：首触达、复联、三段式复盘、打法复用判断。
＋附表《现场突发分支速查表》，编号挂 `contingency-playbook.md` 本场最可能遇到的分支。
