# 跨行业活动策略借鉴库

> 本库是工作台的核心价值之一：园所老师多熟悉本园既有套路，较少接触互联网与其他行业的活动做法。把外面行业成熟、大胆的活动策略搬进来，按幼儿园场景改造好，给老师冲击和可直接借鉴的抓手。推荐动作的组织方式见 `proactive-playbook.md`；借鉴后的落地校验与边界见 `red-lines.md`。

## 一、使用机制：一条借鉴策略按七字段落

| 字段 | 写什么 |
|---|---|
| 借鉴来源 | 哪个行业、什么成熟做法 |
| 迁移形态 | 改成幼儿园招生活动里的什么动作 |
| 熟悉对照物 | 老师本来就认识的对应做法，先搭抓手 |
| 大胆度档位 | 一档稳妥改造／二档新颖动作／三档大胆玩法 |
| 最小试水版 | 家底薄、首试时先做哪一小步 |
| 改造要点 | 降龄、降商业感、去焦虑、去攀比怎么改 |
| 适配条件与红线 | 要什么家底；哪些动作不能碰 |

## 二、大胆度三阶梯（按老师接受度渐进引入）

| 档位 | 定义 | 引入方式 |
|---|---|---|
| **一档 · 稳妥改造** | 熟悉框架里换个做法，几乎无风险 | 可直接进常规方案 |
| **二档 · 新颖动作** | 借外面的新形式，老师少见 | 先小范围一场试，跑顺再放大 |
| **三档 · 大胆玩法** | 有冲击力，需条件和把关人过闸 | 附改造要点与降级版；家底/红线不过不做 |

每条策略都配最小试水版：先一小组家庭、一场活动，验证后再加重。

## 三、分行业种子映射

### 1. 快消 / 零售 / 餐饮

| 外面的成熟策略 | 迁到招生活动的形态（熟悉对照） | 档位 | 试水版与改造要点 |

## 四、明确不迁的部分

以下做法不属于本工作台借鉴范围，提案时直接排除：

- **流量采买、广告投放、付费获客**：不代运营账号、不做投放方案。
- **分销裂变、拉人头返利、多级转介绍奖励**：碰合规与口碑红线。
- **买好评、刷口碑、安排台词伪装家长**：不做虚假背书。
- **焦虑营销、稀缺逼单、"再不报就没名额"式话术**：不制造焦虑。
- **攀比晒娃、排名评比、公开孩子表现优劣**：保护低龄孩子与家长感受。
- **超出本园已开通渠道的线上玩法**：未开通渠道不写进方案。

## 五、面向传统老师的适配

- **先讲熟悉对照，再讲新颖点**：介绍外来打法先说"这跟咱们以前做的 XX 差不多"，再说"外面多加了一步 XX"，降低陌生感。
- **每个三档玩法配最小试水版**：先一场、一小组家庭验证，不直接铺全场。
- **把关人先过闸**：提案后主动自查家底够不够、红线下不下、适龄不适龄；不过闸的换成一档动作。
- **渐进沉淀**：哪条外来打法在本园跑成，连同实践事实记入活动档案表"创新动作/借鉴来源"位，下场可直接调用。
- **沟通起步句**："这个做法别的行业常用，咱们改一改也能用；先小范围试一场，不合适就退回来。"

## 六、取法口径（诚实分层）

- **离线打底**：本库上述种子映射预置在包内，不联网也能查、能用。
- **运行时补充**：环境允许时，AI 可在对话里结合检索补充当下其他行业的新玩法；不把"实时全网搜罗"写成硬承诺，不内置任何城市/场地数据。
- **回到本园**：借鉴落不落地，看本园家底、招生窗口与红线；不照搬外面的激进商业方案。

## 七、回流

跑成的外来打法，复盘时记：借鉴来源行业、本场改造形态、过程事实反馈、是否沉淀为可复用配方；未跑成的也记原因，避免下场重复试错。
