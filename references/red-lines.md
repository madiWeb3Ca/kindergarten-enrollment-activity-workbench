# 红线与使用规则

> 本文件是所有方案、物料、留资动作的硬边界。违反任意一条即视为不合格，必须重写。

## 一、事实检索规则（A4 口径）

1. **检索顺序**：出方案先在当前对话所在项目空间资料库找园所介绍 → 找不到再账号全文兜底 → 仍找不到留待核实占位。
2. **分级取用**：可引用/已确认的事实可进方案；待确认/需复核的留占位；库中无不编。
3. **包内不固化**：skill 包内不写死园所具体事实（班额、名额、人数、收费、师资姓名等）；运行时从母版检索。
4. **人工复核**：时间、地点、联系人、费用、师资、名额一律人工核对；AI 初稿人工复核后对外。
5. **历史数据重核**：复用历史档案时，打法结构可参考，当时事实数字须重新核实。

## 二、承诺红线

- 不承诺招生人数、转化率、报名人数、营收提升、曝光达成值。
- 指标只记录可回填的过程事实，不预设达标线。
- 不写"保证招满""转化率 X%""提升 X"这类表述。

## 三、事实与同行红线

- 不编造园所事实：园名、班额、教师姓名、场地条件、名额、费用不自造。
- 不贬低同行；只讲自己可查证的事实。
- 费用、政策类口径以园方官方与当年公告为准；口述待校正项不得对外引用。

## 四、隐私与合规边界

- 留资自愿；联系方式只用于洽谈跟进，不群发、不买名单。
- 家长信息按岗位受控：线索与联系方式留招生岗受控库，不进品宣共享表；资源库只记合作方信息。
- 合作活动中，线索归园所工作台，合作方不留存家长信息；这一条接洽时先讲明。
- 园方提供的表格与文档只读不写；分析产物在己方账号单开新表/新文件。

## 五、产品边界

- 课后延时课是在读家庭增值服务、另收费，不打包成对外招生引流产品；其老师能力与场地可借用做体验环节。
- 本园没有的独立选修课/兴趣班，不设计相关活动方案。
- 未开通的线上渠道不写进方案。

## 六、能力边界

- 可给资源库规范、活动建议、方案骨架与复盘记录；不承诺"帮你把招生体系建起来"，不代运营账号，不接手日常内容排期与账号发布。
- 不承诺方案带来的招生结果（人数、转化率、报名、营收、曝光）；效果以复盘事实为准。
- 政策细则引用当年公告；不沿用往年日期推下一年。
- 技术操作（音轨分离、格式转换、素材整理、纸质补录）由教练侧/招生岗完成，不向现场老师派技术活。

## 七、待核实占位写法

未确认项在方案中统一写成：

```
【待核实：____（事项）】
```

对外物料中占位必须在人工回填后才能出现；回填前不得把占位内容当事实陈述。
